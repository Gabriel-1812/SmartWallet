# 💸 SmartWallet

SmartWallet é uma aplicação de controle financeiro pessoal para gerenciamento de receitas, despesas e categorias.

O objetivo do projeto é servir como um projeto de portfólio fullstack, bem estruturado, aplicando boas práticas de arquitetura, versionamento e organização de código.

---

## 🚀 Objetivo do Projeto

Criar uma aplicação que permita ao usuário:

- Cadastrar receitas e despesas
- Visualizar saldo mensal
- Organizar gastos por categorias
- Acompanhar histórico financeiro

---

## 🧱 Arquitetura

Este projeto é um **monorepo** dividido em:

```bash
SmartWallet/
├── apps/
│   ├── api   # Backend (Node.js + TypeScript + Express)
│   └── web   # Frontend (React + Vite + TypeScript)
└── package.json
```
